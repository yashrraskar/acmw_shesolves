# SheSolves 2026

A responsive event landing page for **SheSolves 2026**, an ACM-W chapter initiative at PCCOE Pune.

## Overview

- Event: SheSolves 2026
- Venue: New Computer Department Library, PCCOE, Pune 61
- Date: Saturday, September 19, 2026
- Time: 9:00 AM – 6:00 PM
- Contact: acmw@pccoepune.org

## Project structure

- `index.html` — page structure and content
- `css/styles.css` — styling and layout
- `js/script.js` — interactions, form validation, countdown, and admin access

## Features

- Responsive landing page layout
- Event summary, schedule, and participation sections
- Registration form with validation
- Countdown timer to the event date
- Registration management dashboard for viewing and exporting participant data
- Clean and professional visual style

## Run locally

Open `index.html` directly in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit: `http://localhost:8000`

## Notes

This is a front-end only project and does not use a backend service. The data is stored in the browser using local storage.
